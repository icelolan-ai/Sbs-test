# วิธีเปิดเว็บบนเครื่อง

1. แตกไฟล์ ZIP ทั้งโฟลเดอร์ก่อนใช้งาน ห้ามเปิดไฟล์จากใน ZIP โดยตรง
2. ติดตั้ง Python 3 หากเครื่องยังไม่มี สำหรับ Windows ให้เลือก Add Python to PATH ตอนติดตั้ง
3. Windows: ดับเบิลคลิก START-WINDOWS.bat
4. macOS/Linux: เปิด Terminal ที่โฟลเดอร์เว็บ แล้วพิมพ์ sh START-MAC-LINUX.sh
5. เบราว์เซอร์จะเปิด http://localhost:8000/ หากไม่เปิดอัตโนมัติ ให้คัดลอก URL นี้ไปเปิดเอง
6. เปิดหน้าต่างคำสั่งทิ้งไว้ขณะดูเว็บ ปิดเซิร์ฟเวอร์ด้วย Ctrl+C

หากพอร์ตถูกใช้งานอยู่ ให้รัน python server.py --port 8001 หรือ python3 server.py --port 8001 แล้วเข้า http://localhost:8001/

ไฟล์รูป CSS และ JavaScript อยู่ในชุดส่งมอบแล้ว แต่ Google Fonts ลิงก์แผนที่ โซเชียล และหน้ารายละเอียดอบรมภายนอกยังต้องใช้อินเทอร์เน็ต หากโหลดฟอนต์ไม่ได้จะใช้ฟอนต์ระบบแทน

localhost เปิดได้เฉพาะเครื่องที่รันเซิร์ฟเวอร์ ชุดนี้ยังไม่ใช่การติดตั้งบน AWS และไม่ควรเปิดไฟล์ index.html โดยตรงแทนการรันเซิร์ฟเวอร์
